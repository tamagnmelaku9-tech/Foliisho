🚀 Live Cloud Firestore Testing Guide

1. Single Shared Database (Firebase Project: foliisho):

Both the Web Admin, Mobile Web App, and Android APK connect directly to Cloud Firestore. When a driver joins on any phone, their ticket (#, plate, phone) appears instantly in the Coordinator's Live Driver Queue list!

2. Installing as a Phone App (PWA — Recommended, No APK Needed):

  1. On a driver phone, open /driver (or /admin for coordinators).
  2. Tap "📲 Install App" or Chrome menu (⋮) → Install app (iPhone Safari: Share → Add to Home Screen).
  3. Launches full-screen with its home screen icon, offline shell cache, and live Firestore sync!

3. Standalone Routes & Android APK:

  • /admin — Installable Station Coordinator Web Admin PWA.
  • /driver — Installable Driver Radar PWA.
  • Or click "Download Android APK" above if you prefer native APK sideloading.

Install Hawassa Transit App (PWA)

Android (Chrome / Edge):

Tap browser menu (⋮) → "Install app" or "Add to Home screen".

iPhone / iPad (Safari):

Tap Share (⬆️) → "Add to Home Screen".

Tip for Drivers vs Coordinators:

Open /driver before installing on a driver's phone, or /admin before installing on a coordinator device.
