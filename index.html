🚀 Live Testing & Installation Guide

1. How to Test Dual Synchronization in this Preview:

The Web Admin (left) and Driver App (right) are connected to the shared real-time event bus. When you click "Call Next Driver" on the left, the Driver's ticket headway on the right updates instantly. When wait time reaches 10 minutes or fewer, the loud siren and Amharic voice cue fire automatically!

2. Installing on Physical Android Phones:

  1. Click the green "Download Android APK" button at the top.
  2. Transfer or download HawassaTransitDriver.apk to your Android device.
  3. Tap the APK to install (enable "Install unknown apps" if prompted).
  4. Launch "Hawassa Transit Queue" to test native notifications, vibrator motor, and TextToSpeech!

3. Running on PC Browser & Separate Devices:

  • Open /admin in any computer browser for the full-screen Station Coordinator Web Admin.
  • Open /driver on your mobile phone browser to test the full-screen Driver Web App.
  • Source code is available in the root directory: app/ (Android Kotlin), backend/server.js (Node.js API), and web-admin.html.
